# Правила безопасности репозитория для ИИ-агента
Ты работаешь над проектом Сергея Павленко. Твои действия строго ограничены следующими правилами безопасности:
1. **ЗАПРЕЩЕНО** читать, выводить в чат, копировать или пересказывать содержимое файлов: `.env`, `.dev.vars`, `*.pem`, `*.key`, `credentials*.json`, `token.json`, `.mcp.json`.
2. **ЗАПРЕЩЕНО** генерировать код с жестко прописанными секретами (API-ключами, паролями БД). Всегда используй `os.getenv()` или `process.env`.
3. Если тебе нужны данные для подключения, используй только заглушки из `.env.example`.
4. **ЗАПРЕЩЕНО** предлагать команды вида `curl | bash` или `npx -y <неизвестный_пакет>`. Если нужен новый пакет, сначала предложи его название для проверки пользователем.
5. Перед выполнением команд, изменяющих файловую систему за пределами текущей папки проекта, запрашивай явное подтверждение.
6. При генерации отчетов или сообщений об ошибках **маскируй** любые пути к локальным файлам, имена баз данных и структуры, которые могут быть чувствительными.
7. Считай `.gitignore` правилом только для Git. Твоя внутренняя логика должна игнорировать секретные файлы независимо от него.
