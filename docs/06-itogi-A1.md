## 2. Что сломалось и уроки (инциденты → правила)
- Обрезанный флаг winget при копировании (`--accept-source-agreeme`) → команды копируем одним блоком.
- `python -m venv .venv` поверх живого .venv: «Unable to copy venvlauncher.exe»
  (python.exe залочен IDE) → venv создаётся один раз; пересоздание: deactivate → удалить → создать.
- YAML: двоеточие с пробелом внутри значения (`name: gitleaks: ...`) ломает конфиг → такие значения в кавычках.
- `detect-secrets scan --baseline` падает, если файла нет: baseline создаётся перенаправлением
  вывода scan; в PowerShell 5.1 `>` пишет UTF-16, `-Encoding UTF8` — с BOM →
  `Out-File -Encoding ascii` (правило 20).
- Ложное срабатывание forbid-хука на `.env.example`: маска `(^|/)\.env($|\.|/)` запрещала контракт →
  маска с negative lookahead `(?!example$)` (правило 22; маска в МАСТЕР-ДОКУМЕНТЕ тоже исправлена).
- Кириллица в выводе хука = кракозябры в отчёте pre-commit → `sys.stdout.reconfigure(encoding="utf-8")`.
- `git restore --staged` не работает до первого коммита (unborn HEAD) →
  замены: `git rm --cached <file>` или `git add -A` после удаления файла с диска.
- Push 404 «Repository not found»: транслитерация владельца в remote URL не совпала с реальным
  логином (PavlienkoSergheySerg вместо PavlenkoSergeySerg) → URL копируем из адресной строки (правило 23).
- GCM держал чужую учётку → `cmdkey /delete:git:https://github.com` и повторный вход через браузер.
- ExecutionPolicy блокировал Activate.ps1 → `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` (правило 17).
